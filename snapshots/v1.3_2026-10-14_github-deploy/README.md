# موسوعة الذكاء الاصطناعي 🤖

موقع عربي تفاعلي يشرح الذكاء الاصطناعي: تعريفه، نشأته، مراحل تطوره، أنواعه، تطبيقاته، ومستقبله — مع صفحة **سجل زوار** بعدّاد عالمي حقيقي.

## الصفحات
- `index.html` — الصفحة الرئيسية
- `visitors.html` — سجل الزوار (عداد عالمي حي + ترتيب الدول)

## العداد العالمي 🌐
يعمل عبر خدمة [Abacus](https://abacus.jasoncameron.dev) المجانية (بدون مفاتيح سرية في الكود).

## النسخ الاحتياطية 📸
مجلد `snapshots/` يحوي نسخة مع كل تعديل + سجل `CHANGELOG.md` — للاسترجاع:
```powershell
powershell -File restore.ps1
```
