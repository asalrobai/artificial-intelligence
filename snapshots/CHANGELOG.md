### طريقة الرجوع لنسخة سليمة (من GitHub)
1. من صفحة Releases حمّل ملفات النسخة المطلوبة واستبدلها، أو:
2. بالأوامر (بعد أي مشكلة):
```powershell
git fetch --tags
git checkout v1.2 -- index.html visitors.html   # استرجاع ملفات نسخة معينة
```
3. أو محلياً عبر: `powershell -File restore.ps1`

## القاعدة المتبعة من الآن
- مع **كل تعديل** على الموقع: commit + نسخة محلية في `snapshots/` + **Tag وRelease جديد على GitHub** مع التعليق والتاريخ.
- لا تُحذف النسخ القديمة أبداً.

## طريقة الاسترجاع
1. يدوياً: انسخ `snapshots/<اسم-النسخة>/index.html` إلى `index.html` الرئيسي.
2. أو عبر PowerShell من جذر المشروع:
```powershell
Copy-Item -Force "snapshots\v1.0_2026-10-14_baseline\index.html" "index.html"
```
3. أو شغّل: `powershell -File restore.ps1` واختر النسخة من القائمة.
